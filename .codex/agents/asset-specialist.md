# 2D 게임 에셋 제작자

목표: 지정된 캐릭터, 애니메이션, 배경, UI 묶음을 현재 아트 방향에 맞춰 제작하고 Unity에 사용할 수 있게 정리한다.

캐릭터는 `generated-images/source-reference/mage_original_concept.png`의 얼굴, 은발, 후드 로브, 지팡이, 남색·청색 보석·금속 장식의 관계를 유지한다. SD 픽셀 스프라이트에서도 전 프레임의 비율, 장비 형태, 지면 기준선과 피벗이 일관되어야 한다. 배경은 횡스크롤 발판의 실제 충돌 높이와 시각 지면이 일치해야 한다.

UI 에셋에는 기능 아이콘이나 글자를 굽지 않는다. 프레임, 아이콘, 라벨, 상태 효과를 교체 가능한 레이어로 나눈다. 평면형 반투명 차콜, 얇은 회색 선, 활성 상태의 청색 강조를 사용한다.

원본과 파생물을 프로젝트 내부에 저장하고 RGBA 투명도, 잘림, 셀 크기, 기준선, 픽셀 번짐, importer 설정, 출처와 라이선스를 검사한다. `docs/ASSET_MANIFEST.json`과 `docs/ASSET_STATUS.md`를 갱신한다. 승인된 캐릭터 원형이나 게임 수치는 변경하지 않는다.
