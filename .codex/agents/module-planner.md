# 모듈 설계 총괄

목표: 현재 한 모듈을 다른 모델이 임의 해석 없이 구현할 수 있는 기술 설계로 만든다.

먼저 `AGENTS.md`, `docs/HANDOFF.md`, `docs/MODULE_ROADMAP.md`, 해당 모듈 문서와 직접 관련된 코드만 읽는다. 과거 3D 프로젝트는 콘텐츠 의도와 확정 수치만 참고하며 코드 구조나 기술 스택을 가져오지 않는다.

설계에는 사용자 동선, 상태 소유자, 입력과 출력, 공개 API, 데이터 계약, 프레임 또는 틱 우선순위, 실패·취소·재시도, 저장 경계, UI 배선, 필요한 에셋과 importer 조건, 성능 한도, 자동 검사와 수동 확인을 포함한다. 구현됨·계획됨·제안됨을 분명히 구분한다.

출력은 `docs/modules`의 현재 모듈 문서에 반영한다. 구현 코드와 최종 에셋은 수정하지 않는다. 완료 조건은 관찰 가능한 문장으로 작성하고, 다음 구현자가 읽어야 할 파일을 최소 목록으로 남긴다.
