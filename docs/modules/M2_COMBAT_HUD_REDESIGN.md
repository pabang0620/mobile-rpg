# M2 전투 HUD 개편

## 목적

전투 시야를 확보하고 입력 우선순위를 기본공격, 스킬, 기동, 소모품, 자동사냥, 메뉴 순서로 명확하게 표현한다.

## 에셋 계약

`Assets/Game/Art/HudControls.png`는 4×2 동일 셀의 **글리프 전용** 아틀라스다. 좌→우, 위→아래 순서는 HP 물약, MP 물약, 점프, 구르기, 기본공격, AUTO 룬, 햄버거, 가방이다. 글리프 밖은 실제 투명 RGBA이며 테두리, 원, 사각 프레임, 글자, 배경을 포함하면 안 된다.

프레임은 별도 UI 요소다. 원형 슬롯과 사각 슬롯 모두 Icon Sprite를 인자로 받아 조립한다. 새 기능을 추가할 때 완성된 버튼 이미지를 생성하지 말고 글리프만 추가한다.

실제 프레임은 `UiChrome.png`에서 공급한다. `RoundControl`과 `SquareControl`은 Unity 기본 도형 대신 이 아틀라스의 neutral/active Sprite를 사용한다. 코드는 아이콘 교체, 비활성 알파, 쿨다운, AUTO 활성 프레임 선택만 담당한다.

## 상태와 애니메이션

- AUTO OFF: 어두운 원형 프레임, 회색 룬, 정지.
- AUTO ON: 청색 프레임과 룬, 초당 105도 시계 방향 회전.
- 처치 진행: `BattleSession.Kills` 증가를 표시 계층에서 감지하고 5마리 단위 1/5~5/5를 0.55초간 표시한다.
- 스킬 쿨다운과 MP 부족은 기존 Icon 위 텍스트 오버레이로 처리한다.

## 후속 주의사항

- 물약 슬롯은 현재 시각 배선만 되어 있다. 회복/인벤토리 모듈에서 콜백, 수량, 재사용 대기를 도메인 이벤트로 연결한다.
- 던전 목표 모듈이 생기면 Kill 누적 대신 목표별 진행 이벤트가 중앙 알림 값을 제공해야 한다.
- 모바일 safe area에서는 좌우 조작 묶음을 가장자리에 고정하고 상단 중앙 패널만 화면 중앙을 유지한다.

## 표면과 메뉴 규격

- 상태창, 지역 진행, 조작 버튼은 남회색 바탕 알파 0.5~0.65와 회백색 테두리 알파 0.35~0.5를 기본값으로 사용한다.
- AUTO 활성 상태만 청색 반투명 표면, 청색 점멸 테두리, 회전 룬으로 강조한다.
- 햄버거를 누르면 우측 480×720 메뉴 패널이 열린다. 월드는 패널 뒤로 비치며 전체 dim은 0.22로 제한한다.
- 메뉴 항목은 4열 2행 사각 슬롯과 짧은 한글 라벨로 구성한다.
- 던전 선택 화면은 어두운 배경 위 세로형 던전 카드 구조를 사용한다. 카드에는 배경 삽화, 진행률 링, 던전명, 권장 전투력만 둔다.
