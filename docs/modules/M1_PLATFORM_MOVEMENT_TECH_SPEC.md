# M1 횡스크롤 플랫폼 이동 기술 명세

상태: 첫 구현과 검증 완료. 최신 사용자 결정에 따라 벨트스크롤 위아래 보행을 폐기하고 좌우 이동·점프 방식으로 전환했다.

## 플레이 계약
- 이동축은 X 하나다. 위/아래 입력만으로 위치가 변하지 않는다.
- Space 또는 점프 버튼은 지면/발판에 서 있을 때만 점프를 시작한다.
- Shift 또는 회피 버튼은 바라보는 좌우 방향으로 회피한다.
- 점프 중 발판 아랫면은 통과하고 하강 중 윗면을 가로지를 때만 착지한다.
- 발판 끝을 벗어나면 수직속도 0으로 낙하를 시작한다.
- AUTO는 현재 지면에서 X축으로만 추적한다. 높은 발판의 적을 찾아 자동 점프하는 경로 탐색은 M2 범위다.

## 현재 물리 fixture
- 기준 해상도: 1280×720.
- 주 지면 top: y=214, 법사 논리 반높이 90, 서 있는 중심 y=304.
- 점프 초속도: +720px/s, 중력: -1000px/s².
- X 이동 범위: 75~1205, 걷기 150px/s, 회피 550px/s.
- 단방향 발판: `[320,540] top=414`, `[615,840] top=473`, `[895,1118] top=395`.
- 발판 값은 `SapphirePlatformMap.png`의 실제 평평한 윗면과 대응한다.

`BattleSession.Hero.y`는 sprite 이미지 캔버스가 아니라 법사의 논리 중심이다. 발 위치는 `Hero.y - HeroHalfHeight`다. 착지 판정은 이전 발 위치가 surface 이상이고 현재 발 위치가 surface 이하인 하강 frame에서만 성립한다.

## 상태와 취소
`Grounded`, `SupportTop`, `VerticalVelocity`가 수직 상태를 소유한다. 점프는 사망, 세션 종료, 공중, 공격 중에는 거절되며 거절 시 상태를 바꾸지 않는다. 수동 점프는 AUTO를 3초간 유예한다. 회피와 점멸은 Y를 변경하지 않는다.

## 검증
- `horizontal-only-walk`: 위 입력 0.5초 동안 Y 불변.
- `jump-platform-landing`: 상승 확인 후 좌측 단방향 발판 착지.
- 기존 AUTO, 1회 명중, 스킬 거래, 회피 무적, 1회 보상, Close 검사 유지.
- 런타임 스모크는 `jumped=true`, 공중 캡처, 착지 완료를 요구한다.

다음 보강은 jump/fall/land 전용 스프라이트, 플랫폼별 drop-through 규칙, 이동 발판, 사다리/로프 채택 여부, 자동사냥 플랫폼 graph다. 이 항목을 확정하기 전 위 입력을 보행축으로 재사용하지 않는다.
