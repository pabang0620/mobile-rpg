# M0 시작 흐름과 마을 허브

## 확정 사용자 흐름

`로그인 → 서버 선택 → 캐릭터 선택/생성 → 마을 → 사냥터 또는 던전` 순서다. 앱 시작 시 전투를 자동으로 시작하지 않는다. 온라인 계정과 서버가 구현되기 전에는 로그인과 서버 선택이 로컬 스텁임을 화면에 명시한다.

## 현재 구현 범위

- 로컬 게스트 로그인.
- 서버 3개 표시, 루나 1만 선택 가능.
- 최대 4슬롯을 수용하는 캐릭터 선택 구조. 현재 실제 에셋이 확정된 사파이어 메이지만 선택 가능.
- 사파이어 광장 마을에서 A/D 좌우 이동.
- 우측 출정 버튼 또는 포털 근처 Enter로 달빛 회랑 전투 진입.
- 전투 종료 후 마을 귀환, 저장, NPC 상호작용은 후속 모듈에서 연결.

## 소유 상태

`FrontFlowScreen`은 접속 단계와 선택 결과만 소유한다. `BattleSession` 전투 상태를 미리 생성하지 않는다. 마을은 안전 지역이며 자동사냥, 적 스폰, 피해 판정을 실행하지 않는다.

## 에셋 계약

`SapphireTown.png`는 16:9 횡스크롤 허브 배경이다. 지면 윗면은 한 줄로 이어지고 중앙 스폰 공간과 우측 포털이 명확해야 한다. 캐릭터와 NPC는 배경에 굽지 않는다. 로그인·서버·캐릭터 선택은 같은 배경에 반투명 패널을 올려 사용한다.

`WideButton.png`가 로그인, 서버, 캐릭터 확정, 출정 버튼의 공통 외형이다. `UiChrome.png`는 원형·사각·슬롯·바·배지 프레임 아틀라스다. 버튼은 `Frame Sprite > Icon Sprite > Label/State`로 조립한다. 코드에서 단색 사각형이나 원을 최종 버튼 외형으로 만들지 않는다. 새 버튼은 기존 프레임을 재사용하고 기능 고유 글리프만 별도 에셋으로 추가한다.

## 후속 검토

- 캐릭터 슬롯 저장 ID와 표시 순서를 분리한다.
- 인증 실패와 서버 점검 상태는 선택 불가 이유를 보여준다.
- 마을 진입 시 저장 체크포인트를 한 번 기록하고 중복 보상을 만들지 않는다.
- 사냥터 귀환 시 캐릭터 위치는 중앙 스폰 anchor로 복구한다.
