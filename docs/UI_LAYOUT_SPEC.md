# 전투 HUD 배치 계약

기준 해상도는 1280×720, 좌표 원점은 좌하단이다. `HudControls.png`는 테두리 없는 아이콘 글리프 아틀라스이며 프레임과 상태 효과는 코드에서 조립한다. 표면은 월드가 비치는 무채색 남회색 반투명을 기본으로 하고 UI 테두리에는 금색을 사용하지 않는다. 캐릭터 원화의 금색 장식은 그대로 유지한다.

## 구현 목록

- 좌상단 상태창은 284×72로 줄이고 초상, 레벨, HP, MP만 표시한다.
- `달빛 회랑`과 구간 진행은 상단 중앙의 330×50 패널에 둔다.
- 골드, 상시 처치 수, 좌측 퀘스트 패널, 우측 스테이지 패널은 제거한다.
- 처치 순간 중앙에 `1 / 5` 형식의 진행을 0.55초간 페이드 표시한다.
- 기본공격은 우하단 112px 주 버튼이며 스킬 4개가 좌상단 반원으로 감싼다.
- 점프와 구르기는 기본공격 왼쪽 아래의 독립 버튼이다.
- HP/MP 물약 두 칸은 스킬 묶음 위에 둔다.
- AUTO는 원형 프레임이다. 켜지면 청색으로 빛나고 내부 룬이 계속 회전한다.
- 메뉴는 우측 상단 사각 햄버거 버튼 하나로 연다. 우측 480px 반투명 패널에 가방, 스킬, 장비, 퀘스트, 던전, 레이드, 상점, 설정을 모은다.

## 재사용 가능한 슬롯 구조

모든 조작 슬롯은 `Frame > Mask(optional) > Icon > State Overlay > Count/Cooldown` 계층을 따른다. 아이콘 이미지 자체에 테두리를 포함하지 않는다. 원형 프레임은 전투, 스킬, 물약, AUTO에 쓰고 사각 프레임은 햄버거, 메뉴 항목, 장비·인벤토리 슬롯에 쓴다. `RoundControl`과 `SquareControl`은 전달받은 Sprite를 내부 Icon에 배치하므로 다른 스킬이나 기능으로 교체할 수 있어야 한다.

## 검토 규칙

- 프레임을 바꾸지 않고 Icon Sprite만 바꿔 슬롯 용도를 교체할 수 있어야 한다.
- 기본공격과 스킬은 겹치지 않되 하나의 조작 군집으로 읽혀야 한다.
- AUTO OFF에서도 룬이 보이며 ON에서는 색과 회전 모두로 상태를 구분한다.
- 햄버거 외 개별 메뉴 바로가기는 전투 HUD에 두지 않는다.
- 월드 중앙의 캐릭터, 몬스터, 발판을 상시 HUD가 가리지 않아야 한다.

## 월드 기준

`SapphirePlatformMap.png`의 보이는 석재 윗면을 기준으로 주 지면 충돌선은 y=214다. 공중 발판 윗면은 왼쪽부터 y=414, 473, 395다. 법사의 발 피벗은 충돌선과 일치해야 하므로 주 지면에서 중심 y=304, 표시 180×180을 사용한다. 일반 고블린은 같은 y=214 발 피벗을 사용한다. 보행은 X축만 사용하며 Y는 점프, 중력, 발판 착지가 결정한다.
