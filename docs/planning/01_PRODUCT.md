# 제품 기획 v1

## 근거와 결정 수준

사용자 확정: 기존 기획/지침을 참고한 새 게임, 제노니아 계열 감각, Unity와 C#, 필요한 에셋 생성, MVP 이후 확장 가능한 산출물, 구현보다 planning 우선, 하위 모델이 실행 가능한 명세.

원본 확인: 사파이어 메이지, 로컬 시작 흐름, 마을/전투 구분, 스킬 4개, HP/MP 물약, AUTO, 차콜/회색/청색 UI, 한글 프로젝트 폰트, UI와 규칙 분리. 원본의 횡스크롤·점프·발판은 새 방향과 충돌하므로 승계하지 않는다.

잠정 설계 결정: 초기 제노니아 계열의 탑다운 2D, 가로 화면, 오프라인 싱글, 메이지 1직업, 직접 조작 우선. 온라인 서버 선택은 MVP에서 제외하고 프로필 선택으로 대체한다. 기존 캐릭터의 얼굴/머리/로브/지팡이/색 관계를 유지한다. 새 게임명은 ‘사파이어: 달빛의 균열’ 가칭으로 사용한다.

누락 자료: 원본의 `../DOCUMENTATION` 및 별도 에셋 생성 프롬프트 파일을 찾지 못했다. 원본이 언급하는 40스킬/경제 테이블을 복원하거나 확정 기획이라고 주장하지 않는다. 아래 수치는 새 플레이테스트용 기준이다.

## 경험 목표

플레이어는 작은 마을에서 균열 조사를 의뢰받고, 숲에서 마법 연계와 회피를 익힌 뒤 폐허의 수호자를 쓰러뜨린다. 새 장비로 공격 효율이 좋아지는 변화가 한 판 안에 보인다. 이동, 적의 예고, 명중, 보상, 다음 목적지가 모바일 화면에서 바로 읽혀야 한다.

핵심 루프: 마을 의뢰 → 필드 탐험/전투 → 재료/장비/경험치 획득 → 귀환과 보상 → 장착/강화 → 보스 던전 → 첫 장 완료.

## 첫 장 범위

| 구성 | 제작 범위 | 완료 증거 |
|---|---|---|
| 시작 | 새 프로필/이어하기/설정, 로컬 슬롯 1개 | 재실행 후 이어하기 |
| 마을 | 사파이어 광장, NPC 3명: 안내자·상인·대장장이 | 대화/의뢰/구매/강화가 실제 상태 변경 |
| 필드 | 연결된 숲 구역 2개, 장애물/출구/체크포인트 | 전 구역 이동, 막힌 곳 통과 불가 |
| 던전 | 입구 전투방 → 정예방 → 보스방, 고정 연결 | 문 잠금/해제와 단일 결과 정산 |
| 적 | 근접 고블린, 원거리 정령, 돌진 늑대, 기존 종의 정예 변형 | 세 행동 유형별 예고/피격/사망 |
| 보스 | 균열 수호자 1종, HP 50%에서 2페이즈 | 원형 충격파/직선 돌진/소환 패턴 |
| 플레이어 | 8방향 이동, 4방향 아트, 마법 3연계, 스킬 4개, 회피 | 수동 입력과 모바일 입력 동일 판정 |
| 성장 | 레벨 1~5, 장비 3슬롯, 장비 정의 9종, 강화 +0~+3 | 장착/강화 능력치가 저장 후 유지 |
| 퀘스트 | 튜토리얼·처치·재료·정예·보스·귀환 총 6개 | 수락/진행/보상 상태와 중복 방지 |
| 편의 | HP/MP 물약, 메뉴, 체크포인트, 설정, 선택 AUTO | 수동 개입 우선, 전투 중 메뉴 일시정지 |

첫 장은 수동 첫 플레이 20~30분을 목표로 조정한다. 이는 검증 전 목표 시간이다. 길이 달성을 위해 강제 대기나 반복 처치 수를 늘리지 않는다.

## 전투와 조작

월드는 XY 평면, 중력/점프 없음. 대각 이동 속도 정규화. 입력은 WASD/방향키 또는 좌측 가상 스틱. J/공격 버튼 기본공격, 1~4 스킬, Shift 회피, E 상호작용, Q HP물약, F MP물약, T AUTO, Esc 메뉴. 모든 키/터치 경로는 같은 명령에 연결한다.

기본공격은 지팡이 마법탄 3연계다. 공격 중 추가 입력 1회만 버퍼링하며 장시간 누름은 회복 종료 뒤 다음 공격을 요청한다. 자동 타겟은 조준 보조이며, 대상이 없으면 바라보는 방향으로 발사한다. 벽 너머 타격과 화면 밖 원격 타격을 허용하지 않는다.

스킬: 비전탄(단일), 서리 파동(주변 둔화), 점멸(짧은 이동/무적), 보호막(일시 피해 흡수). 각 스킬을 레벨 1/2/3/4에서 개방한다. 1~4 슬롯은 고정, 후속 스킬 교체는 콘텐츠 확장 단계에 추가한다.

AUTO는 필드 한정 보조 기능이며 첫 진입 OFF. 수동 이동/공격/회피 시 즉시 개입하고 3초 후 재개. 보스방 진입과 재실행 시 OFF. NPC 대화·아이템 구매·장비 강화·퀘스트 보상 수령은 AUTO가 수행하지 않는다.

사망: 필드에서는 체크포인트 부활, 던전에서는 실패 결과 후 마을 귀환. 금전 패널티 없음. 부활 시 HP/MP 전부 회복. 필드의 이미 확정된 획득은 유지하고, 실패한 던전의 임시 보상은 폐기한다. 이 정책을 입장/실패 화면에 표시한다.

## UI 기준

기존 차콜 반투명 표면, 얇은 회색 선, 활성 청색을 유지한다. 한글은 동봉 NotoSansCJKkr 폰트. 프레임/아이콘/숫자/쿨다운 분리. 이미지에 동적 텍스트를 굽지 않는다.

1280×720 기준: 좌상단 HP/MP/레벨, 상단 중앙 지역/보스 HP, 우상단 메뉴, 좌하단 스틱, 우하단 공격 중심 스킬 4개와 회피/물약/AUTO. 점프 버튼 삭제. 퀘스트 목표는 접을 수 있는 한 줄로 표시한다. 메뉴는 가방/장비/퀘스트/설정 4개만 실제 제공하고 미구현 레이드 버튼을 넣지 않는다.

16:9, 20:9, 4:3에서 safe area 안에 HUD를 배치한다. 터치 영역은 48 논리 픽셀 이상을 출발점으로 실제 기기에서 조정한다. 색 외에 아이콘/문구로 쿨다운·잠금·선택을 구분한다. 메뉴/대화/포커스 상실은 게임 시간을 정지하고 복귀 시 눌림 상태를 초기화한다.

## MVP 이후 출시 단계

1. 첫 장 품질 고정: 조작/저장/성장/아트/Windows 빌드와 Android 실기기 검증.
2. 콘텐츠 확장: 새 구역/퀘스트/장비/적 데이터를 추가하고 동일 서비스로 동작하는 것을 증명. 두 번째 직업은 스킬과 아트 제작량 산정 후 진행.
3. 출시 준비: 대상 기기 성능, 오디오/접근성, 로컬라이징, 저장 마이그레이션, 개인정보/스토어 요건, QA, 배포 서명.
4. 별도 프로젝트 결정: 온라인 계정·서버 권한·동기화·멀티플레이·과금. 현재 오프라인 구조를 서버 지원 완료로 표현하지 않는다.

최종 인수물은 Unity 프로젝트, Windows 실행 빌드, 가능할 경우 검증한 Android 빌드, 플레이 영상/캡처, 테스트 결과, 에셋 원본/프롬프트/권리 기록, 알려진 한계, 콘텐츠 추가 예제다. Android SDK나 기기가 없으면 해당 검증을 미완료로 명시한다.
