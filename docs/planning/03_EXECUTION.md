# 실행 백로그와 인수 조건

상태는 모든 작업이 TODO다. 앞선 원본 복사와 배경 시안 생성은 아래 작업 완료로 계산하지 않는다. 순서대로 한 작업을 완료한 후 다음 작업으로 간다. 각 작업 착수 시 공개 타입/메서드 시그니처와 테스트 입력을 해당 작업 명세에 고정한다.

| ID | 선행 | 변경 책임 | 필수 검증 및 인수 |
|---|---|---|---|
| P00 | 없음 | 새 Unity 프로젝트 초기화, asmdef, 문서 우선순위, 패키지 고정 | 빈 Boot 씬으로 Windows 빌드; 원본 런타임 혼입 없음 |
| P01 | P00 | 순수 Vec2/tick/명령 결과/콘텐츠 정의와 검증기 | 중복 ID·깨진 참조·음수 비용 fixture 거절 |
| P02 | P01 | 프로필/저장/백업/거래 경계 | 최초 저장, 재로드, 손상 백업, 쓰기 실패, 중복 거래 검사 |
| P03 | P01 | 이동/충돌/카메라/키보드·가상스틱 | 상하좌우/대각 동일속도, 벽/모서리, 포커스 이탈 입력 초기화 |

## 작업 크기 제한

한 작업이 다섯 개 이상의 새 책임이나 두 개 이상의 독립 서비스를 요구하면 `Pxx-A/B`로 나눈다. P04는 공격기/투사체/회피/표현, P07은 인벤토리/성장/상점·강화, P09는 방 진행/보스/정산으로 나눠 실행한다. 관련 없는 UI·아트·경제 리팩터링을 한 변경에 섞지 않는다.

각 작업의 Definition of Done: 명세 작성 → 구현 → 규칙 테스트 → 실제 씬/입력 연결 → 실행 검증 → 인계 갱신. 코드 존재, 버튼 존재, 이전 프로젝트의 통과 로그는 완료 근거가 아니다. 씬 연결 전에는 IMPLEMENTED_UNWIRED, 자동 검증만 통과하면 TESTED_NOT_PLAYED로 기록한다.

## 최종 인수표

- 깨끗한 환경에서 문서의 Unity 버전으로 열어 컴파일 오류 없이 빌드된다.
- 새 게임부터 보스 처치·마을 보상까지 1회 수동 완주한다. 20~30분 목표 대비 실제 시간을 기록한다.
- 저장 후 종료/이어하기, 저장 실패, 손상 백업, 던전 중 종료에서 지정 정책이 지켜진다.
- 일반/정예/보스 사망 이벤트 중복, 퀘스트 보상 연타, 정산 재시도에서 보상이 늘지 않는다.
- PC와 모바일 입력이 같은 명령을 사용하고 다중 터치 이동+공격+회피가 유실되지 않는다. 실기기 없으면 모바일 입력은 미검증으로 남긴다.
- 16:9/20:9/4:3 캡처에서 가려진 HUD/잘린 한글/화면 밖 버튼이 없다.
- 10분 AUTO 필드 테스트에서 벽 끼임/무진행/메모리 지속 증가를 조사한다. 실제 측정치와 장치 정보를 남긴다.
- 대상 Android 기기에서 60fps 목표, 미달 시 30fps 모드와 품질 조정. 장치 미정 상태에서 성능을 통과했다고 기록하지 않는다.
- 정의 데이터만으로 적 변형 1종·장비 1종·퀘스트 1개 추가 예제를 만들어 코어 수정 없이 동작함을 보여준다.
- 생성 아트의 원본/프롬프트/최종 사용 파일/해시/검수 상태가 연결되어 있다. 최종 렌더의 임시 이미지와 누락 오디오를 별도로 표시한다.

## 기록 파일

후속 구현 시 `docs/tasks/Pxx.md`, `docs/HANDOFF.md`, `docs/DECISIONS.md`, `verification/summary.md`를 생성한다. 로그는 정확한 커맨드/시간/종료코드, 캡처는 씬/해상도/입력 경로를 기록한다. 비실행 검사는 STATIC, 에디터 검사는 EDITMODE, 게임 실행 검사는 PLAYMODE/PLAYER, 기기 검사는 DEVICE로 구별한다.

## 위험 관리

가장 큰 불확실성은 방향별 캐릭터 애니메이션 품질과 누락된 원본 기획이다. P04 단계에서 4방향 idle/run/기본공격 샘플을 먼저 검수해 제작 가능성을 확인한다. 정적 캐릭터의 흔들기·회전만으로 최종 애니메이션 완료를 선언하지 않는다. 생성 결과가 기준을 충족하지 못하면 해당 에셋은 BLOCKED 상태와 실패 근거를 남기고 영향을 받지 않는 시스템부터 진행한다.

계획 변경은 결정 로그에 근거/영향/수정할 계약/재실행 테스트를 적는다. 후속 모델이 어려운 기능을 조용히 삭제하거나 단일 거대 스크립트로 우회하면 인수 실패다.
