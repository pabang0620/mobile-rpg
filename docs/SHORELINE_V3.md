거품은 바위벽 아래 수면에 놓이도록 한다.

잔디 소재, 수초/수련/바위 없이 자연스러운 청록색 흐름을 담은 수면 소재, 이끼와 균열이 있는

## 제약

64px 모듈 크기, 방향별 연결, 외곽 호환성, 안정 문자열 ID, 충돌과 이동 동선을 유지한다.
원본에서 소재를 읽어 타일로 제작하고 맵 일러스트를 잘라 배경으로 사용하지 않는다.
변형 타일의 연결 부분은 같게 유지하고 내부 소재 선택을 다르게 한다.
지면의 투명한 테두리 아래에는 수변용 토양을 배치해 물이 땅과 벽 사이에 비치지 않게 한다.
