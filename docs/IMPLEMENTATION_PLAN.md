# 2D 첫 전투 배선 계획

사용자가 둔 법사 idle PNG와 공격16PNG를 검사했다. 공격 일부는 경계 잘림/다른 셀의 잔여물 때문에 전체16프레임을 곧바로 사용하지 않는다. 02/06/09/14의 깨끗한 핵심 포즈를 고정발 기준으로 연결하고 재제작 필요한 프레임을 인계한다. 새 이미지로 법사를 재설계하지 않는다.

## 첫 모듈 범위
독립 Unity2D 전투장에 기존 생성 배경/아이콘과 투명 법사/고블린을 복제해 배선한다. 계정·경제 저장 없이 세션 XP/골드/레벨을 통해 자동사냥 피드백을 확인한다. 샘플 맵은 달빛 폐허이며 확정 첫 지역을 바꾸는 결정이 아니다.

Domain/BattleSession: 시간/대상/거리/HP/MP/공격시점/쿨다운/회피/사망/보상/재생성/새 세션 소유.
Runtime/BattleScreen: 실제 uGUI, 포인터 조작, 키보드, 에셋 표시, 타이밍에 따른 법사 포즈, 예고/투사체/피격 표시.
Editor/BuildGame: 이미지 임포트, 참조를 직렬화한 씬 생성, 규칙 검사, 별도 Windows 빌드.

## 규칙과 실패
- 스킬4개는 비전탄/얼음 파동/점멸/보호막의 실험 기능. 확정40스킬 테이블을 대신하지 않는다.
- 동일 공격은 한 번만 명중. 대상이 죽거나 범위 이탈하면 적용하지 않는다. MP는 수락된 명령에서 한 번만 소비.
- AUTO OFF는 유지. 수동 이동/공격은 AUTO ON 상태의 사냥을3초 쉬게 한다. 새 run은 모든 지연 타격/상태를 폐기.
- 적 사망은 XP/골드 한 번, 재생성 전 시체 표시 후 지연. 사망한 주인공은 재도전 전 공격 불가.
- 전투 예고는 실제 타격방향과 범위로 표시. GUI 그림이 공격판정을 소유하지 않는다.

## 검증
순수 규칙에서 좌우 전용 보행/점프·발판 착지/반복공격/MP부족/회피/사망/한번보상/AUTO OFF/새run격리 검사.
실행 빌드에서 생성 씬 로드, UI 참조, 자동사냥 처치·성장, 스킬/쿨다운, 재도전/사망을 자동 검사하고 카메라 렌더로 HUD 포함 캡처한다. GUI를 카메라 캔버스로 만들어 offscreen 캡처에 포함한다. 실제 터치 기기 검증은 별도다.

## 2026-09-10 구현 결과
Windows 빌드, 12개 이미지 임포트, 실제 투명/보이는 픽셀을 가진 에셋 8개, 도메인 규칙 10개, 자동사냥 1킬과 점프 런타임 스모크가 통과했다. 법사/몬스터의 발 기준을 새 플랫폼 맵의 주 지면에 맞추고 월드 레이어와 HUD 레이어를 분리했다. 8개 생성 메뉴 타일과 실제 RGBA 공통 패널을 가방/스킬/던전/레이드 버튼에 연결했다. 최종 캡처는 `captures/latest-battle.png`, `captures/latest-jump.png`, `captures/latest-menu.png`다. 현재 완료 범위는 첫 전투장 한 세션과 메뉴 shell이며 전체 던전·장비·레이드 완성을 뜻하지 않는다.

## 횡스크롤 플랫폼 전환
최신 사용자 결정으로 자유로운 위아래 보행을 제거했다. 새 `SapphirePlatformMap.png`를 생성·복제하고 주 지면과 세 단방향 발판을 좌표화했다. A/D 좌우 이동, Space 점프, 중력, 하강 착지, 발판 이탈 낙하, Shift 회피를 구현했다. 도메인 규칙 검사는 10개로 늘었고 런타임 보고서는 실제 공중 상태와 착지 완료를 요구한다. 전환 증거는 `captures/latest-battle.png`, `captures/latest-jump.png`다.

## 2026-09-12 시작 흐름·마을·UI 개편

앱 진입을 전투 직행에서 로그인 → 서버 → 캐릭터 → 마을 → 출정으로 변경했다. 로그인과 서버는 온라인 연동 전 로컬 스텁이다. 사파이어 광장에서는 전투가 실행되지 않으며 A/D 이동과 우측 포털 출정만 제공한다.

사용자 레퍼런스에 맞춰 UI를 평면형 반투명 차콜/회색과 청색 활성 강조로 전면 교체했다. 프레임 `UiChrome.png`, 기능 글리프 `HudControls.png`, 와이드 버튼 `WideButton.png`를 분리했다. 한글은 `NotoSansCJKkr-Regular.otf`를 프로젝트 에셋으로 포함하고 버튼 패딩과 overflow 정책을 공통화했다. HP/MP 물약 거래 검사를 포함해 도메인 검사는 11개, 투명 에셋 검사는 11개다. 최신 디자인 기준은 `generated-images/ui/reference/hud-redesign-v2.png`다.
