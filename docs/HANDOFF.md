# 현재 인계 상태

## 실행 흐름
`Run-Lighthaven2D.cmd` 또는 Windows 빌드를 실행하면 로그인 화면이 열린다. 게스트 로그인 → 루나 1 → 사파이어 메이지 → 사파이어 광장으로 진행한다. 마을에서는 A/D로 이동하고 우측 출정 버튼 또는 포털 근처 Enter로 달빛 회랑에 진입한다.

전투 조작은 A/D 이동, Space 점프, Shift 구르기, J 기본공격, 1~4 스킬, T AUTO, R 재도전이다. 마우스/터치 버튼도 같은 command를 사용한다. HP/MP 물약은 실제 회복과 수량 차감을 수행한다.

## 구현 위치
- `FrontFlowScreen.cs`: 로그인, 서버, 캐릭터 선택, 마을, 출정 전환과 앞단 캡처.
- `BattleSession.cs`: 이동, 점프, 공격, 회피, 물약, AUTO, 보상 규칙.
- `BattleScreen.cs`: 전투 HUD, 입력, 에셋 표시, 메뉴와 스모크 캡처.
- `BuildGame.cs`: 16개 이미지 임포트, 11개 알파 검사, 11개 도메인 검사, Windows 빌드.

## 시각 기준
`generated-images/ui/reference/hud-redesign-v2.png`가 최신 전투 HUD 기준이다. 표면은 평면형 반투명 차콜, 얇은 회색 테두리, 활성 청색 강조를 쓴다. 좌상단은 작은 상태 스트립, 상단 중앙은 지역명과 대상 HP, 좌하단은 낮은 불투명도 이동 패드, 우하단은 기본공격 중심의 스킬/기동/물약/AUTO 군집이다. 메뉴는 우측 480px 패널이다.

## 검증 상태
2026-09-12 Windows 빌드 성공. 실제 투명 에셋 검사 11개, 도메인 검사 11개, 자동사냥 1킬·점프·착지·메뉴 런타임 스모크가 통과했다.

## 남은 한계
로그인과 서버는 로컬 스텁이다. 캐릭터 슬롯은 4개 구조이나 법사만 활성화돼 있다. 마을 NPC 상호작용, 저장, 전투 귀환, 정식 던전 런과 결과 정산은 후속 모듈이다. 현재 공격 애니메이션은 핵심 4포즈이며 최종 16프레임 세트가 아니다. 모바일 safe area와 실제 터치는 아직 기기 검증 전이다.
