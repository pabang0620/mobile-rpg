# 전체 퀄리티 개선 계획 (2026-09-28)

기준: 현재 가장 완성도가 높은 화면은 **슬라임 왕국(Modular64 V3)**. 나머지 화면·연출을 이 수준으로 끌어올리는 것이 목표다.
사용자 지적: "캐릭터 위치, 스킬 이펙트 위치 전부 어색함", "스킬 이펙트 누끼가 이상함".

## 1단계 - 이번 작업에서 처리 (코드/에셋 반영, Unity 실행 검증은 사용자 손테스트)

| # | 항목 | 원인 | 조치 |
|---|---|---|---|
| 1 | 스킬 이펙트 누끼(잘린 직선 경계, 옆 프레임 조각, 뿌연 사각 헤이즈) | AI 생성 시트가 Unity의 균등 8×N 슬라이스 격자를 지키지 않아 프레임이 칸 경계를 넘음. 알파 1~8 헤이즈가 시트의 약 40% | `tools/art_qa/clean_vfx_frames.py`로 실제 사용되는 시트 5장을 재배치. 실제 빈틈에서 프레임 경계를 찾고, 각 프레임을 자기 칸 안(여백 4px)으로 이동하거나 필요할 때만 축소. 헤이즈는 smoothstep으로 제거. 캔버스·격자·PPU는 그대로라서 월드 크기와 피벗 규칙은 변하지 않음. 결과: 경계에 닿는 칸 0개, 헤이즈 약 90% 감소 |

## 2단계 - 이펙트 연출 품질 (2026-09-28 완료, 손테스트 대기)

완료:
- 스킬 버튼 쿨다운 표시(`SkillCooldownOverlay`): 어두운 부채꼴, 남은 초, 마나 부족 시 흐림
- 타격 시점을 각 이펙트의 정점 프레임에 맞춤. 고드름과 번개창은 타일마다 순서대로 맞고, 한 번 시전에 같은 몬스터는 1회만 맞음
- 발광 셰이더(`SpriteGlow`)를 마법사 전체와 전사 베기·방패에 적용
- 몬스터 치명타 규칙을 Domain으로 이동(`CombatEngine.MonsterCritChance`)
- 전사 방패막기 이펙트가 플레이어를 따라다님

원래 계획 항목:

- 발광계 이펙트(마법사 전체, 전사 베기·방패)에 가산(Additive) 블렌딩 머티리얼 적용. 지금은 알파 합성이라 밝은 잔디 위에서 탁해 보인다. 흙·바위 계열(대지강타, 회오리, 돌진 먼지)은 알파 유지.
- 스킬별 재생 시간·크기·이동량을 범위 표시(타일)와 맞추는 표 작성: 기술마다 "시작 프레임 → 타격 프레임 → 소멸"이 실제 피격 지연(`HitDelaySeconds`)과 맞는지 확인.
- 스킬 버튼 쿨다운 표시(방사형 fill 오버레이)와 마나 부족 시 흐리게 표시.
- 피격 스파크, 데미지 숫자의 크기와 색 규격 통일.

## 3단계 - 마을(VillageHub)을 Modular64로 전환

- 슬라임 왕국과 같은 파이프라인(TS01~TS08, `ApprovedEnvironmentBuild`)으로 재구성. 예전 `VillageHubTerrainBuilder`의 베이크드 지형, 울타리 방식은 폐기.
- 사용하지 않는 에디터 코드(`SlimeSeamlessTileBaker`, `BuildAllWithCute`/`MapBaker`) 정리.

## 4단계 - 캐릭터·몬스터 아트 일관성

- 플레이어와 슬라임의 타일 대비 크기, 외곽선 두께, 그림자 규격 통일(슬라임 왕국 소재 톤 기준).
- 이동, 공격 모션 프레임의 발 위치 흔들림 실측(알파 bbox) 후 보정.

## 5단계 - 구조

- Application 계층(`GameApp`) 도입. Presentation이 Domain을 직접 조립하지 않게 함.
- 몬스터 AI, 피격 규칙을 Domain으로 이동(몬스터 치명타 15%도 카탈로그화).
- PlayMode 스모크 테스트: 스킬 사용 → 마나·쿨다운 → 몬스터 사망 → 경험치.

## 검증 방식

- 이 클라우드 환경에는 Unity Editor가 없다. Domain과 Domain 테스트는 mono(mcs)와 NUnit 대체 셈으로 컴파일·실행한다(2026-09-28 기준 전부 통과).
- Presentation/Editor 코드는 컴파일하지 못했다. 사용자 PC에서 Unity를 열어 컴파일을 확인하고, `SapphireSceneBuilder.BuildEverything()`과 `ApprovedEnvironmentBuild.Build`로 씬을 재생성한 뒤 손테스트해야 한다.
- VFX PNG가 바뀌었으므로 Unity가 열릴 때 자동 재임포트되며, 임포터가 프레임 피벗을 다시 계산한다.
