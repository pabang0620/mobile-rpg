# 결정 기록

## D001 탑다운 제품 방향

원본의 횡스크롤 이동 계약을 새 제품에 적용하지 않는다. 월드는 20×11 단위 XY 평면이며 화면 표시 때 중심 좌표로 변환한다. 점프와 중력은 없다.

## D002 첫 장을 독립 실행 가능한 경계로 사용

전체 라이브 서비스 분량 대신 마을→필드→던전→보스→귀환 성장 루프를 실제로 연결한다. 콘텐츠는 카탈로그와 서비스로 분리하여 새 정의 추가가 코어 전투를 바꾸지 않게 한다.

## D003 오프라인 저장과 거래

저장 파일은 체크섬 envelope, revision, 최근 transaction ID를 가진다. Unity/Mono 환경에서 `File.Replace`가 UnauthorizedAccessException을 내는 경우 검증된 이전 파일을 `.bak`으로 복사한 뒤 임시 파일을 이동하는 복구 가능한 대체 경로를 사용한다.

## D004 렌더 좌표 변환

CombatWorld는 `[0,20]×[0,11]`, Presentation은 `[-10,10]×[-5.5,5.5]`를 사용한다. GameApp만 `(x-10,y-5.5)` 변환을 수행한다.

## D005 생성 캐릭터 시트 거절

4×4 방향 시트는 캐릭터 정체성과 방향 표현은 양호했으나 체크무늬가 RGB 픽셀로 포함됐다. 배경 추출 재시도도 진짜 알파를 만들지 못했다. 빌더는 `MageDirectional.png`를 런타임에서 제외하며 기존 투명 MageIdle을 사용한다.
