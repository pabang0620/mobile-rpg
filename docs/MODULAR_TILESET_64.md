월드 1칸 = 1 Unity unit. PNG에는 구분선·ID·문자·체크무늬를 그리지 않는다.

## TS01 셀 계약

문서 좌표는 왼쪽 위부터 1행/1열. 아래 슬롯은 0부터 시작하는 행 우선 번호다.

| 슬롯 | ID | 내용 |
|---|---|---|
| 0~46 | G001~G047 | 정규화한 8방향 마스크 오름차순 |
| 47 | — | 투명 예비 |
| 48~59 | G048~G059 | 호환 가능한 잔디 내부 변형 12종 |
| 60~63 | — | 투명 예비 |
| 64~87 | P001~P024 | 사용자 설계의 명명된 길 모양/프리셋 |
| 88~95 | — | 투명 예비 |
| 96~142 | PA001~PA047 | 완전한 흙길 자동 연결 세트 |
| 143 | — | 투명 예비 |
| 144~155 | PV001~PV012 | 흙길 내부 변형 |
| 156~255 | — | 확장용 투명 예비 |

P 프리셋만으로 모든 복합 경계를 처리하지 않는다. 자동 맵 생성에는 PA를 사용한다.
P의 Narrow/Wide는 별도 폭 프로파일이며 서로 다른 폭을 바로 접속하지 않는다.
넓은 도로는 이웃한 여러 셀의 점유 상태로 구성한다. 단일 64px 타일이 2칸을 덮는 것이 아니다.
G048~G059와 PV는 모든 방향이 연결된 내부 셀에서만 사용한다.

## 생성 및 확인 방법

Unity 메뉴: `Sapphire > Modular Tiles > Build Independent Ground Test`.
배치 진입점: `Sapphire.EditorTools.ModularTiles.ModularGroundBuilder.Build`.
Unity 6000.5.9f1 프로젝트 경로는 저장소의 `client` 폴더다.

- 필수 입력: `Sources/GrassMaster.png`, `Sources/DirtMaster.png`.
- 시트: `Art/World/Modular64/TS01_Ground_Path_64.png`.
- 명세: 같은 폴더의 `TS01_Ground_Path_64.csv` (좌표는 Unity 기준 왼쪽 아래 원점).
- Tile 에셋: 같은 폴더의 `Tiles/*.asset`. 각각 직렬화된 Sprite를 포함한다.
- 씬: `Assets/Sapphire/Scenes/ModularGroundTest.unity`.
- 검수 출력: 저장소 루트의 `verification/modular-ground-test.png`, `modular-ground-validation.txt`.

원본은 수정하지 않고 작은 영역을 nearest 방식으로 샘플링한다. 외곽 소재는 주기적으로
이어지게 좌표를 구성하고, 내부는 불규칙한 패치로 변형한다. 잔디/흙 각 12색 팔레트로
정규화한다. 생성 결과는 투명 또는 완전 불투명 픽셀만 사용한다.
주기 소재는 서로 떨어진 원본 샘플 4개를 가중 합성한 뒤 팔레트로 정규화한다.
좌우/상하 거울반사로 무늬를 반복하지 않는다. 이 처리는 소재 제작 단계이며,
맵 위 타일의 크기를 늘리거나 서로 포개는 처리가 아니다.
직선 경계에는 모서리 깎기를 적용하지 않고, 실제 볼록/오목 모서리만 처리한다.
변형 배치는 좌표 해시를 사용해 일정한 대각선 순서로 반복되는 현상을 줄인다.
원본 소재가 반투명이어도 RGB를 바닥 재질로 읽고 원본 알파는 사용하지 않는다.
바닥의 불투명 영역은 255, 지형 바깥은 0으로 연결 마스크가 결정한다.
색상 정보가 보장되지 않는 완전 투명 원본 픽셀이 있으면 입력을 거절한다.
현재 생성기는 저장된 타일 데이터를 조립하는 Editor 도구다. 런타임 자동 타일 갱신
컴포넌트, 캐릭터 이동/충돌, 높이/계단 처리를 구현했다고 해석하지 않는다.

## 연결 규칙

- 비트: N=1, NE=2, E=4, SE=8, S=16, SW=32, W=64, NW=128.
- 대각선 비트는 양옆 직교 이웃이 모두 있을 때만 유효하다.
- 256개 입력을 정규화하면 47개의 지형 연결 모양이 된다.
- 셀 외곽의 색과 알파는 호환되는 인접 모양과 일치해야 한다.
- 지면 변형은 공유 경계를 유지하며 내부 무늬를 바꾼다. 외곽에 평평한 단색 띠를 두르지 않는다.
- 물가/길가의 자연스러운 굴곡은 인접 셀 접점에서 이어져야 한다.
- 바닥 타일을 확대하거나 포개어 틈을 가리지 않는다. 셀은 정확히 1×1이다.
- 정규화된 이미지와 직접 조립된 미리보기는 동일한 타일 픽셀을 사용한다.
- 그림자, 나무, 바위, 물결은 지면 소재에 합쳐 넣지 않는다.

## 향후 씬 통합

물 → 물결 → 평지 → 길 → 각 높이의 그림자/절벽/상판/계단 → 장식 순으로 구성한다.
큰 오브젝트는 발 위치를 기준으로 캐릭터와 정렬한다.
기존 Ground/Collision 기반 이동과 연동할 때 높이·계단 방향·다리 통행 규칙을 명시적으로 연결한다.
그림자/물결/장식의 알파를 보고 통행 가능 여부를 추측하지 않는다.
다리는 물 위 구간과 양쪽 육지의 접속까지 검증한다.

## 검수

자동 검수: 마스크 256→47, 인접 타일의 RGBA 경계, 변형 타일 경계, 투명 예비 셀,
시트 크기와 ID 중복, 재생성 후 동일한 연결 규칙을 확인한다.
육안 검수: 큰 잔디 평지, 작은 섬, L/U/십자, 1칸 통로, 불규칙 경계, 흙길 교차로,
임의 변형을 섞은 바닥에서 반복되는 사각 윤곽과 실제 연결감을 확인한다.
수치 검수가 통과해도 최종 시각 품질이나 실제 플레이 검수가 완료된 것으로 표현하지 않는다.
