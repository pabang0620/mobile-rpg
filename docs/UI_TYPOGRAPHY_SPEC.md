# UI 타이포그래피와 패딩 규격

## 폰트 에셋

모든 한글 UI는 `Assets/Game/Fonts/NotoSansCJKkr-Regular.otf`를 사용한다. 라이선스는 같은 폴더의 `OFL-NotoSansKR.txt`에 보관한다. OS 설치 폰트를 런타임에 찾지 않는다. 고정 로고를 제외한 레벨, 수량, 서버 상태, 버튼 라벨은 이미지에 굽지 않는다.

## 버튼 라벨

- 프레임 이미지의 알파 경계를 먼저 trim하고 그 결과를 버튼 Rect에 맞춘다.
- 텍스트 안전영역은 버튼 Rect에서 좌우 18px, 상하 6px를 뺀 영역이다.
- 단일 행 라벨은 수평·수직 중앙 정렬한다.
- 활성 라벨 18px, 비활성 라벨 18px와 50~65% 명도를 사용한다.
- 라벨이 안전영역을 넘으면 글자 크기를 임의로 줄이지 말고 문구를 줄이거나 버튼 규격을 키운다.

## 화면 제목과 보조문

- 화면 제목 32~36px, 상단 안전 여백 70px 이상.
- 지역명 24px, 보조문 14~16px.
- 제목과 첫 콘텐츠 사이 80px 이상, 버튼 간 세로 간격 12px 이상.
- 캐릭터 카드 이름은 초상 아래 24px 이상 떨어뜨리고 프레임 테두리와 18px 이상 간격을 둔다.

## 검증

1280×720에서 로그인, 서버, 캐릭터 선택, 마을을 각각 캡처한다. 텍스트가 프레임 선과 겹치거나 프레임의 시각 중심에서 3px 이상 벗어나면 실패다. 동적 한글과 숫자 조합을 함께 확인한다.
